# Synthetic matcher calibration v1
Run `python3 scripts/train-matcher.py` from the project. Requires numpy. Dataset labels are literal weighted rubric labels, not generated by the model being evaluated. Family splits occur before alias/title variants. Missing means not evidenced, not that the person lacks a skill. The tiny dataset is deliberately repetitive and tests the scoring rubric only; it is not representative of real applicants, does not measure extraction or semantic gap accuracy, and cannot establish fairness or hiring predictions. The least-squares scorer learns 100/50/0 weights, ties the deterministic baseline, and has no claim of superiority. Existing alias/title and transfer-skill tests remain mandatory. General LLM weights are unchanged. Future work needs independently expert-reviewed, consented examples and broader occupation coverage.
