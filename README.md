# Career Growth Map

https://careergraph-fawn.vercel.app/ --- reference

Build me an app that helps people figure out what skills they’re missing for a job, and what order to learn them in.

I want users to be able to sign up and log in, upload a PDF or DOCX resume, and add job descriptions they’re interested in. The app should extract skills and experience from the resume in the background, compare the resume against job posts in a smart way even when the wording doesn’t match exactly, and then show a clear skill gap analysis with a step by step learning path, not just a random list of missing skills.

Please include separate roles for job seekers and recruiters, a clean dashboard where users can track resume uploads and job matches, and status updates while resume parsing is running. Make it fast, reliable, and ready to run locally with Docker. If anything needs current setup details, look up the latest docs online.
